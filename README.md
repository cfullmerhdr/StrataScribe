# Strata Scribe

A Progressive Web App (PWA) for geotechnical field logging of borings, soil samples, rock cores, groundwater observations, GPS locations, and drilling activities.

Built for field use on phones, tablets, and desktops, Strata Scribe supports offline operation, automatic IndexedDB project storage, JSON project backups, structured CSV exports, boring profile visualization, groundwater mapping, and project-level QA/QC summary figures.

### Features

- Soil and rock logging with structured descriptions
- GPS capture and boring location mapping
- Groundwater observations and profile visualization
- Surface condition logging
- Recovery and RQD tracking
- Automatic IndexedDB project storage
- JSON project backup and restore
- Structured CSV exports
- Multi-boring profile comparison tools
- Project summary figures and drilling statistics
- Installable PWA for Android, iOS, Windows, and macOS

Designed to reduce paperwork, improve data consistency, and simplify geotechnical field documentation.
